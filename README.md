# Lumia - Ultra Light Suite for Xiaomi
Suite d'apps ultra moderne, légère et rapide.

**Modules:**
- `app` -> Lumia Launcher (HOME optimisé, cache d'icônes LRU, load sur IO thread, 3-4MB)
- Prochainement: Gallery (MediaStore + pagination), Files, Dialer

**Build dans Android Studio:** Open Project -> Lumia

**Installer sur Xiaomi:**
adb install app/build/outputs/apk/debug/app-debug.apk
Puis choisir Lumia comme lanceur par défaut.

Design: Material You dynamique, Compose, 0 pub.
